# woofWoofCPU v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build woofWoofCPU v1 — a menu bar dog that watches per-app CPU and memory, escalates napping → sniffing → growling → barking when a hog stays over its limit, and lets you Quit (⌥ Kill), Snooze or Ignore it from a drop-down popover.

**Architecture:** All logic lives in a local Swift package `WoofCore`: libproc sampling, grouping helpers under their app, breach tracking, mood state machine, settings and actions. It has no UI and is fully unit-tested with fakes. The `WoofWoofCPU` app target is thin AppKit + SwiftUI: an `NSStatusItem` with an animated dog, a non-activating `NSPanel` popover, and a settings window. A main-actor `AppCoordinator` connects them. The Xcode project is generated by XcodeGen from `project.yml`.

**Tech Stack:** Swift 6 (strict concurrency), AppKit, SwiftUI, Observation, ServiceManagement, IOKit.ps, libproc (Darwin), Swift Testing, XcodeGen, Xcode 27.

**Spec:** `docs/superpowers/specs/2026-10-01-woofwoofcpu-design.md`. Read it before starting any task. Research background is in `docs/research/2026-10-01-similar-apps.md`.

**Provenance:** every code block in this plan was compiled and tested in a scratch prototype on 2026-10-01: 62 package tests pass, the app type-checks under Swift 6, and the XcodeGen build succeeds with warnings treated as errors. Copy code verbatim unless a step says otherwise.

## Global Constraints

- macOS deployment target **14.0**; Swift language mode **6**. Builds must have **zero warnings** (`SWIFT_TREAT_WARNINGS_AS_ERRORS: YES` for the app).
- **No third-party runtime dependencies.** XcodeGen is a dev tool only.
- Bundle id `com.woofwoofcpu.app`; product name `woofWoofCPU`; `os.Logger` subsystem `com.woofwoofcpu`.
- Agent app: `LSUIElement = YES`, **no App Sandbox**, hardened runtime on, ad-hoc signing (`CODE_SIGN_IDENTITY: "-"`).
- `WoofCore` must not import AppKit or SwiftUI. Anything needing AppKit is injected (e.g. `PosixSignaller(quitApp:)`).
- Always build and test through `make` (`make test`, `make test FILTER=<Suite>`, `make build`, `make run`). The Makefile exports `DEVELOPER_DIR` for Xcode's toolchain. The Command Line Tools' Swift Testing plugin fails on multi-file test targets.
- Shell commands: never `cd`. Run from the repo root and pass paths; use `git -C <dir>` if you need another directory.
- Commit messages: **one line, no body, no trailers**, and never mention Claude/Anthropic/model names or add Co-Authored-By/session lines. The repo owner's rules override any harness default.
- Code comments: short, only what the code can't say (contracts, constraints, why). Match the comment density of the code below.
- User-facing copy uses the dog voice from spec §9; numbers come from `Formatting`.

## Review Focus

These failure modes are implied by the spec but no unit test exercises them. Reviewers and the final manual checklist (Task 14) must check them explicitly:

1. **The popover over a full-screen app or another Space.** It must appear and be clickable without leaving full screen. Owner: Task 12 (`collectionBehavior`, fallback anchor). Manual check in Task 14.
2. **Quit of an app with unsaved documents.** It must stay polite: the app shows its save dialog, the row shows "Asking politely…" then "Still here — hold ⌥ to Kill", and nothing escalates to SIGKILL by itself. Unit test `quitFallsBackToSIGTERMWhenAppQuitUnavailable` pins "Quit never sends SIGKILL" (Task 8). The UI path is a manual check.
3. **Sleep/wake.** After waking from a long sleep the dog must not bark instantly. `WatchPipeline.resetTimers` is unit-tested (Task 8); the wiring (`NSWorkspace.didWakeNotification` → reset + `Sampler.reset`) is Task 10 and needs a manual check.
4. **Self-cost.** woofWoofCPU itself must average under 1% of one core while calm. The prototype measured 0.1%; recheck in Task 14 with Activity Monitor over 5 minutes.
5. **Processes of other users / root.** They must never crash or mislead: they are skipped by the sampler (Task 4 test `liveSnapshotIncludesThisProcess` plus `EPERM` handling). Any mixed-ownership entity has Quit/Kill disabled with a tooltip; `otherUsersEntitiesCannotBeActedOn` is in Task 8.

```swift
import Foundation

public enum Resource: String, Codable, CaseIterable, Sendable {
    case cpu
    case memory
}

/// PIDs are reused by the kernel; the start time disambiguates.
public struct ProcessIdentity: Hashable, Codable, Sendable {
    public let pid: Int32
    public let startMicros: UInt64

    public init(pid: Int32, startMicros: UInt64) {
        self.pid = pid
        self.startMicros = startMicros
    }
}

/// One process as read from the kernel in a single snapshot.
public struct RawProcess: Equatable, Sendable {
    public var identity: ProcessIdentity
    public var ppid: Int32
    public var uid: UInt32
    public var name: String
    public var path: String?
    public var responsiblePID: Int32?
    /// Cumulative user + system CPU time, already converted to nanoseconds.
    public var cpuTimeNanos: UInt64
    /// `ri_phys_footprint` — matches Activity Monitor's "Memory" column.
    public var memoryBytes: UInt64

    public init(
        identity: ProcessIdentity,
        ppid: Int32 = 1,
        uid: UInt32 = 501,
        name: String,
        path: String? = nil,
        responsiblePID: Int32? = nil,
        cpuTimeNanos: UInt64 = 0,
        memoryBytes: UInt64 = 0
    ) {
        self.identity = identity
        self.ppid = ppid
        self.uid = uid
        self.name = name
        self.path = path
        self.responsiblePID = responsiblePID
        self.cpuTimeNanos = cpuTimeNanos
        self.memoryBytes = memoryBytes
    }

    public var pid: Int32 { identity.pid }
}

/// A process plus the CPU % computed from the previous snapshot.
public struct ProcessSample: Equatable, Sendable {
    public var process: RawProcess
    /// 100 = one full core (Activity Monitor convention).
    public var cpuPercent: Double

    public init(process: RawProcess, cpuPercent: Double) {
        self.process = process
        self.cpuPercent = cpuPercent
    }

    public var memoryBytes: UInt64 { process.memoryBytes }
}

public protocol ProcessSource: Sendable {
    func snapshot() -> [RawProcess]
}
```

`Packages/WoofCore/Sources/WoofCore/Sampling/MachTime.swift`:

```swift
import Darwin

/// rusage CPU times are Mach absolute ticks, not nanoseconds; on Apple Silicon the timebase is 125/3.
public enum MachTime {
    public static func nanoseconds(_ ticks: UInt64, numer: UInt32, denom: UInt32) -> UInt64 {
        let product = ticks.multipliedFullWidth(by: UInt64(numer))
        return UInt64(denom).dividingFullWidth(product).quotient
    }

    public static let timebase: (numer: UInt32, denom: UInt32) = {
        var info = mach_timebase_info_data_t()
        mach_timebase_info(&info)
        return (info.numer, info.denom)
    }()

    public static func nanoseconds(_ ticks: UInt64) -> UInt64 {
        nanoseconds(ticks, numer: timebase.numer, denom: timebase.denom)
    }
}
```

`Packages/WoofCore/Sources/WoofCore/Sampling/CPUCalculator.swift`:

```swift
import Foundation

/// Turns cumulative CPU times into a per-tick CPU %.
public struct CPUCalculator: Sendable {
    private var lastCPU: [ProcessIdentity: UInt64] = [:]
    private var lastTime: TimeInterval?

    public init() {}

    /// `now` is monotonic seconds. Processes seen for the first time report 0%.
    public mutating func samples(from processes: [RawProcess], at now: TimeInterval) -> [ProcessSample] {
        let elapsed = lastTime.map { now - $0 } ?? 0
        var next: [ProcessIdentity: UInt64] = [:]
        next.reserveCapacity(processes.count)
        let result = processes.map { process -> ProcessSample in
            next[process.identity] = process.cpuTimeNanos
            var percent = 0.0
            if elapsed > 0, let previous = lastCPU[process.identity], process.cpuTimeNanos >= previous {
                percent = Double(process.cpuTimeNanos - previous) / (elapsed * 1e9) * 100
            }
            return ProcessSample(process: process, cpuPercent: percent)
        }
        lastCPU = next
        lastTime = now
        return result
    }

    public mutating func reset() {
        lastCPU = [:]
        lastTime = nil
    }
}
```

```swift
import Foundation

/// Stable identity of what the dog judges; also the key for ignore lists and snoozes.
public enum EntityKey: Hashable, Codable, Sendable {
    case app(bundleID: String)
    case process(path: String)
}

/// Either an app (its main process plus helpers, values summed) or a standalone process.
public struct Entity: Identifiable, Equatable, Sendable {
    public let key: EntityKey
    public let displayName: String
    /// `/Applications/Foo.app` for app entities; nil for standalone processes.
    public let bundlePath: String?
    /// The app's own process (not a helper), when it is running.
    public let mainPID: Int32?
    /// Sorted by CPU, highest first.
    public let members: [ProcessSample]
    public let cpuPercent: Double
    public let memoryBytes: UInt64
    /// False when any member belongs to another user or root.
    public let ownedByCurrentUser: Bool

    public var id: EntityKey { key }
    public var isApp: Bool { bundlePath != nil }

    public init(
        key: EntityKey,
        displayName: String,
        bundlePath: String?,
        mainPID: Int32?,
        members: [ProcessSample],
        ownedByCurrentUser: Bool
    ) {
        self.key = key
        self.displayName = displayName
        self.bundlePath = bundlePath
        self.mainPID = mainPID
        self.members = members.sorted { $0.cpuPercent > $1.cpuPercent }
        self.cpuPercent = members.reduce(0) { $0 + $1.cpuPercent }
        self.memoryBytes = members.reduce(0) { $0 + $1.memoryBytes }
        self.ownedByCurrentUser = ownedByCurrentUser
    }

    /// CPU in percent, memory in bytes.
    public func value(for resource: Resource) -> Double {
        switch resource {
        case .cpu: cpuPercent
        case .memory: Double(memoryBytes)
        }
    }
}
```

```swift
import Foundation

public struct AppInfo: Equatable, Sendable {
    public let bundleID: String
    public let name: String

    public init(bundleID: String, name: String) {
        self.bundleID = bundleID
        self.name = name
    }
}

public protocol AppInfoProvider: Sendable {
    func appInfo(bundlePath: String) -> AppInfo?
}

/// Reads `CFBundleIdentifier` / display name from the bundle's Info.plist, cached per path.
public final class BundleAppInfoProvider: AppInfoProvider, @unchecked Sendable {
    private let cache = NSCache<NSString, Box>()
    private final class Box { let info: AppInfo?; init(_ info: AppInfo?) { self.info = info } }

    public init() {}

    public func appInfo(bundlePath: String) -> AppInfo? {
        if let hit = cache.object(forKey: bundlePath as NSString) { return hit.info }
        let info = Bundle(path: bundlePath).flatMap { bundle -> AppInfo? in
            guard let id = bundle.bundleIdentifier else { return nil }
            let name = (bundle.object(forInfoDictionaryKey: "CFBundleDisplayName") as? String)
                ?? (bundle.object(forInfoDictionaryKey: "CFBundleName") as? String)
                ?? AppGrouper.fallbackName(bundlePath: bundlePath)
            return AppInfo(bundleID: id, name: name)
        }
        cache.setObject(Box(info), forKey: bundlePath as NSString)
        return info
    }
}

/// Folds processes into app entities (helpers under their app) and standalone process entities.
public struct AppGrouper: Sendable {
    public let selfPID: Int32
    public let currentUID: UInt32
    public let appInfo: any AppInfoProvider

    public init(selfPID: Int32, currentUID: UInt32, appInfo: any AppInfoProvider) {
        self.selfPID = selfPID
        self.currentUID = currentUID
        self.appInfo = appInfo
    }

    public func group(_ samples: [ProcessSample]) -> [Entity] {
        let byPID = Dictionary(samples.map { ($0.process.pid, $0) }, uniquingKeysWith: { first, _ in first })
        var buckets: [EntityKey: (name: String, bundlePath: String?, members: [ProcessSample])] = [:]
        var order: [EntityKey] = []

        for sample in samples {
            let pid = sample.process.pid
            guard pid != selfPID, pid != 0 else { continue }

            let key: EntityKey
            let name: String
            let bundlePath = appBundlePath(for: sample, byPID: byPID)
            if let bundlePath {
                let info = appInfo.appInfo(bundlePath: bundlePath)
                key = .app(bundleID: info?.bundleID ?? bundlePath)
                name = info?.name ?? Self.fallbackName(bundlePath: bundlePath)
            } else {
                key = .process(path: sample.process.path ?? sample.process.name)
                name = sample.process.name
            }

            if buckets[key] == nil {
                buckets[key] = (name, bundlePath, [])
                order.append(key)
            }
            buckets[key]?.members.append(sample)
        }

        return order.compactMap { key in
            guard let bucket = buckets[key] else { return nil }
            return Entity(
                key: key,
                displayName: bucket.name,
                bundlePath: bucket.bundlePath,
                mainPID: bucket.bundlePath.flatMap { Self.mainPID(in: bucket.members, bundlePath: $0) },
                members: bucket.members,
                ownedByCurrentUser: bucket.members.allSatisfy { $0.process.uid == currentUID }
            )
        }
    }

    /// Only bundled code (inside a `.app` or `.xpc`) is grouped; plain CLI tools stay standalone,
    /// otherwise a runaway `node` started from Terminal would be blamed on Terminal.
    func appBundlePath(for sample: ProcessSample, byPID: [Int32: ProcessSample]) -> String? {
        guard let path = sample.process.path,
              path.contains(".app/") || path.contains(".xpc/") else { return nil }
        if let responsible = sample.process.responsiblePID,
           responsible != sample.process.pid,
           let responsiblePath = byPID[responsible]?.process.path,
           let app = Self.outermostApp(in: responsiblePath) {
            return app
        }
        return Self.outermostApp(in: path)
    }

    public static func outermostApp(in path: String) -> String? {
        guard let range = path.range(of: ".app/") else {
            return path.hasSuffix(".app") ? path : nil
        }
        return String(path[..<range.lowerBound]) + ".app"
    }

    /// The member whose executable sits directly in the app (exactly one `.app/` in its path).
    static func mainPID(in members: [ProcessSample], bundlePath: String) -> Int32? {
        members.first { sample in
            guard let path = sample.process.path, path.hasPrefix(bundlePath + "/") else { return false }
            return path.components(separatedBy: ".app/").count == 2
        }?.process.pid
    }

    public static func fallbackName(bundlePath: String) -> String {
        let last = (bundlePath as NSString).lastPathComponent
        return last.hasSuffix(".app") ? String(last.dropLast(4)) : last
    }
}
```

```swift
import Darwin
import os

/// Reads every visible process via libproc. Processes owned by root or other users
/// usually fail `proc_pid_rusage` without privileges and are skipped.
public final class LibprocProcessSource: ProcessSource, @unchecked Sendable {
    private let pathCache = OSAllocatedUnfairLock<[ProcessIdentity: String]>(initialState: [:])
    private let responsibleFn: (@convention(c) (pid_t) -> pid_t)?

    public init() {
        // Undocumented libsystem symbol (what Activity Monitor uses); absent → path-based grouping only.
        typealias Fn = @convention(c) (pid_t) -> pid_t
        let handle = dlopen(nil, RTLD_NOW)
        responsibleFn = dlsym(handle, "responsibility_get_pid_responsible_for_pid")
            .map { unsafeBitCast($0, to: Fn.self) }
    }

    public func snapshot() -> [RawProcess] {
        let pids = Self.allPIDs()
        var result: [RawProcess] = []
        result.reserveCapacity(pids.count)
        var seen = Set<ProcessIdentity>()
        for pid in pids where pid > 0 {
            guard let info = Self.bsdInfo(pid), let usage = Self.rusage(pid) else { continue }
            let identity = ProcessIdentity(
                pid: pid,
                startMicros: UInt64(info.pbi_start_tvsec) * 1_000_000 + UInt64(info.pbi_start_tvusec)
            )
            seen.insert(identity)
            let responsible = responsibleFn?(pid)
            result.append(RawProcess(
                identity: identity,
                ppid: Int32(info.pbi_ppid),
                uid: info.pbi_uid,
                name: Self.name(from: info),
                path: path(for: identity),
                responsiblePID: (responsible ?? -1) > 0 ? responsible : nil,
                cpuTimeNanos: MachTime.nanoseconds(usage.ri_user_time &+ usage.ri_system_time),
                memoryBytes: usage.ri_phys_footprint
            ))
        }
        let live = seen
        pathCache.withLock { cache in cache = cache.filter { live.contains($0.key) } }
        return result
    }

    private func path(for identity: ProcessIdentity) -> String? {
        if let cached = pathCache.withLock({ $0[identity] }) { return cached }
        var buffer = [CChar](repeating: 0, count: 4 * Int(MAXPATHLEN))
        guard proc_pidpath(identity.pid, &buffer, UInt32(buffer.count)) > 0 else { return nil }
        let path = String(decoding: buffer.prefix(while: { $0 != 0 }).map(UInt8.init(bitPattern:)), as: UTF8.self)
        pathCache.withLock { $0[identity] = path }
        return path
    }

    private static func allPIDs() -> [pid_t] {
        let estimate = proc_listallpids(nil, 0)
        guard estimate > 0 else { return [] }
        var pids = [pid_t](repeating: 0, count: Int(estimate) + 128)
        let count = pids.withUnsafeMutableBufferPointer {
            proc_listallpids($0.baseAddress, Int32($0.count * MemoryLayout<pid_t>.size))
        }
        return Array(pids.prefix(Int(max(count, 0))))
    }

    private static func bsdInfo(_ pid: pid_t) -> proc_bsdinfo? {
        var info = proc_bsdinfo()
        let size = Int32(MemoryLayout<proc_bsdinfo>.size)
        return proc_pidinfo(pid, PROC_PIDTBSDINFO, 0, &info, size) == size ? info : nil
    }

    private static func rusage(_ pid: pid_t) -> rusage_info_v4? {
        var usage = rusage_info_v4()
        let status = withUnsafeMutablePointer(to: &usage) {
            $0.withMemoryRebound(to: rusage_info_t?.self, capacity: 1) {
                proc_pid_rusage(pid, RUSAGE_INFO_V4, $0)
            }
        }
        return status == 0 ? usage : nil
    }

    private static func name(from info: proc_bsdinfo) -> String {
        withUnsafeBytes(of: info.pbi_name) { raw in
            String(decoding: raw.prefix(while: { $0 != 0 }), as: UTF8.self)
        }
    }
}
```

```swift
    /// CPU: percent (100 = one core). Memory: fraction of physical RAM (0...1).
    public var threshold: Double
    /// Seconds a value must stay over `threshold` before the dog barks.
    public var window: TimeInterval

    public init(threshold: Double, window: TimeInterval) {
        self.threshold = threshold
        self.window = window
    }
}

public struct Limits: Codable, Equatable, Sendable {
    public var cpu: Limit
    public var memory: Limit

    public init(cpu: Limit, memory: Limit) {
        self.cpu = cpu
        self.memory = memory
    }

    public subscript(resource: Resource) -> Limit {
        switch resource {
        case .cpu: cpu
        case .memory: memory
        }
    }

    /// Threshold in the same unit as `Entity.value(for:)` (percent or bytes).
    public func thresholdValue(for resource: Resource, physicalMemory: UInt64) -> Double {
        switch resource {
        case .cpu: cpu.threshold
        case .memory: memory.threshold * Double(physicalMemory)
        }
    }
}
```

```swift
import Foundation

public struct BreachKey: Hashable, Sendable {
    public let entity: EntityKey
    public let resource: Resource

    public init(entity: EntityKey, resource: Resource) {
        self.entity = entity
        self.resource = resource
    }
}

public struct Breach: Equatable, Sendable {
    /// Unique per breach episode; a new episode for the same key gets a new id.
    public let id: Int
    public let key: BreachKey
    public let since: TimeInterval
    /// 0...1 — fraction of the window spent over the limit.
    public let progress: Double
    public let lastValue: Double
}

/// Tracks, per (entity, resource), how long a value has stayed over its limit.
public struct BreachTracker: Sendable {
    /// A breach continues while the value stays above this fraction of the limit.
    public static let hysteresis = 0.9
    /// Consecutive ticks below the hysteresis band that end a breach.
    public static let calmTicksToEnd = 3

    private struct State: Sendable {
        let id: Int
        let since: TimeInterval
        var calmTicks: Int
        var lastValue: Double
    }

    private var states: [BreachKey: State] = [:]
    private var nextID = 1

    public init() {}

    public mutating func update(
        entities: [Entity],
        limits: Limits,
        physicalMemory: UInt64,
        now: TimeInterval
    ) -> [Breach] {
        var present = Set<BreachKey>()
        for entity in entities {
            for resource in Resource.allCases {
                let key = BreachKey(entity: entity.key, resource: resource)
                present.insert(key)
                let value = entity.value(for: resource)
                let threshold = limits.thresholdValue(for: resource, physicalMemory: physicalMemory)
                if var state = states[key] {
                    if value > threshold * Self.hysteresis {
                        state.calmTicks = 0
                    } else {
                        state.calmTicks += 1
                    }
                    state.lastValue = value
                    states[key] = state.calmTicks >= Self.calmTicksToEnd ? nil : state
                } else if value > threshold {
                    states[key] = State(id: nextID, since: now, calmTicks: 0, lastValue: value)
                    nextID += 1
                }
            }
        }
        // An entity that disappeared (quit, killed, exited) ends its breaches at once.
        states = states.filter { present.contains($0.key) }

        return states.map { key, state in
            let window = limits[key.resource].window
            let progress = window > 0 ? min(1, max(0, (now - state.since) / window)) : 1
            return Breach(id: state.id, key: key, since: state.since, progress: progress, lastValue: state.lastValue)
        }
        .sorted { $0.id < $1.id }
    }

    public mutating func reset() {
        states = [:]
    }
}
```

```swift
import Foundation

public enum DogMood: String, CaseIterable, Codable, Sendable {
    case napping, sniffing, growling, barking, sulking, proud
}

/// Turns breaches into the dog's mood and emits each breach's alert at most once.
public struct MoodEngine: Sendable {
    public static let proudDuration: TimeInterval = 10

    public private(set) var mood: DogMood = .napping
    /// Breaches whose alert popover is currently open.
    public private(set) var openAlertIDs: Set<Int> = []
    private var sulkingIDs: Set<Int> = []
    private var alertedIDs: Set<Int> = []
    private var ignoredIDs: Set<Int> = []
    private var proudUntil: TimeInterval?

    public init() {}

    /// Returns the breaches that reached their window on this tick (the caller barks + opens the popover).
    @discardableResult
    public mutating func evaluate(
        breaches: [Breach],
        isMuted: (EntityKey) -> Bool,
        paused: Bool,
        now: TimeInterval
    ) -> [Breach] {
        if paused {
            openAlertIDs = []
            sulkingIDs = []
            proudUntil = nil
            mood = .napping
            return []
        }

        let allIDs = Set(breaches.map(\.id))
        let active = breaches.filter { !isMuted($0.key.entity) && !ignoredIDs.contains($0.id) }
        let activeIDs = Set(active.map(\.id))

        // An alerted breach that ended (not merely muted) was dealt with — be proud.
        if !openAlertIDs.union(sulkingIDs).subtracting(allIDs).isEmpty {
            proudUntil = now + Self.proudDuration
        }
        openAlertIDs.formIntersection(activeIDs)
        sulkingIDs.formIntersection(activeIDs)
        alertedIDs.formIntersection(allIDs)
        ignoredIDs.formIntersection(allIDs)

        let newAlerts = active.filter { $0.progress >= 1 && !alertedIDs.contains($0.id) }
        for breach in newAlerts {
            alertedIDs.insert(breach.id)
            openAlertIDs.insert(breach.id)
            sulkingIDs.remove(breach.id)
        }

        if let until = proudUntil, now >= until { proudUntil = nil }

        let maxProgress = active.map(\.progress).max()
        if !openAlertIDs.isEmpty {
            mood = .barking
        } else if !sulkingIDs.isEmpty {
            mood = .sulking
        } else if proudUntil != nil {
            mood = .proud
        } else if let maxProgress {
            mood = maxProgress >= 0.5 ? .growling : .sniffing
        } else {
            mood = .napping
        }
        return newAlerts
    }

    /// The alert popover was closed without acting (Esc / click outside).
    public mutating func alertDismissed() {
        sulkingIDs.formUnion(openAlertIDs)
        openAlertIDs = []
        if !sulkingIDs.isEmpty { mood = .sulking }
    }

    /// "Ignore": mute this breach episode only. A later episode can bark again.
    public mutating func ignore(breachID: Int) {
        ignoredIDs.insert(breachID)
        openAlertIDs.remove(breachID)
        sulkingIDs.remove(breachID)
    }

    public mutating func reset() {
        self = MoodEngine()
    }
}
```

```swift
public enum SnoozeDuration: String, CaseIterable, Sendable {
    case fifteenMinutes, oneHour, untilTomorrow

    public var displayName: String {
        switch self {
        case .fifteenMinutes: "15 minutes"
        case .oneHour: "1 hour"
        case .untilTomorrow: "Until tomorrow"
        }
    }

    /// "Until tomorrow" means the next 06:00 local time.
    public func until(from now: Date, calendar: Calendar = .current) -> Date {
        switch self {
        case .fifteenMinutes: return now.addingTimeInterval(15 * 60)
        case .oneHour: return now.addingTimeInterval(60 * 60)
        case .untilTomorrow:
            return calendar.nextDate(
                after: now,
                matching: DateComponents(hour: 6, minute: 0, second: 0),
                matchingPolicy: .nextTime
            ) ?? now.addingTimeInterval(24 * 60 * 60)
        }
    }

public final class SettingsStore {

    public private(set) var snoozes: [EntityKey: Date] { didSet { save(snoozes, Keys.snoozes) } }
    public var pausedUntil: Date? { didSet { save(pausedUntil, Keys.paused) } }

    public init(defaults: UserDefaults = .standard, now: Date = Date()) {
        self.defaults = defaults
        limitsSetting = Self.load(LimitsSetting.self, Keys.limits, defaults) ?? .preset(.balanced)
        let rows = defaults.object(forKey: Keys.rows) as? Int ?? Self.defaultRowsShown
        rowsShown = min(max(rows, Self.rowsShownRange.lowerBound), Self.rowsShownRange.upperBound)
        skinID = defaults.string(forKey: Keys.skin) ?? "pixel"
        soundMuted = defaults.bool(forKey: Keys.muted)
        ignoreList = Self.load(Set<EntityKey>.self, Keys.ignore, defaults) ?? []
        snoozes = (Self.load([EntityKey: Date].self, Keys.snoozes, defaults) ?? [:]).filter { $0.value > now }
        pausedUntil = Self.load(Date?.self, Keys.paused, defaults) ?? nil
    }

    public var limits: Limits { limitsSetting.limits }

    public func isMuted(_ key: EntityKey, now: Date) -> Bool {
        if ignoreList.contains(key) { return true }
        if let until = snoozes[key], until > now { return true }
        return false
    }

    public func isPaused(now: Date) -> Bool {
        guard let pausedUntil else { return false }
        return pausedUntil > now
    }

    public func alwaysIgnore(_ key: EntityKey) {
        ignoreList.insert(key)
    }

    public func removeFromIgnoreList(_ key: EntityKey) {
        ignoreList.remove(key)
    }

    public func snooze(_ key: EntityKey, until: Date) {
        snoozes[key] = until
    }

    public func cancelSnooze(_ key: EntityKey) {
        snoozes[key] = nil
    }

    public func pruneExpired(now: Date) {
        let live = snoozes.filter { $0.value > now }
        if live.count != snoozes.count { snoozes = live }
        if let pausedUntil, pausedUntil <= now { self.pausedUntil = nil }
    }

    private enum Keys {

        static let rows = "rowsShown"
        static let skin = "skinID"

        static let snoozes = "snoozes"
        static let paused = "pausedUntil"
```

```swift
import Darwin

public enum SignalResult: Equatable, Sendable {
    case sent
    case notAllowed
    case alreadyGone
    case failed(Int32)
}

/// Seam over `kill(2)` and NSRunningApplication so actions are testable.
public protocol ProcessSignaller: Sendable {
    func send(_ signal: Int32, to pid: Int32) -> SignalResult
    func isAlive(_ pid: Int32) -> Bool
    /// Polite app quit (Apple Event, lets the app ask to save). False when no such app is running.
    func quitApp(pid: Int32) -> Bool
}

public struct PosixSignaller: ProcessSignaller {
    private let quitAppHandler: @Sendable (Int32) -> Bool

    /// `quitApp` is injected by the app target (NSRunningApplication.terminate) to keep this module AppKit-free.
    public init(quitApp: @escaping @Sendable (Int32) -> Bool) {
        quitAppHandler = quitApp
    }

    public func send(_ signal: Int32, to pid: Int32) -> SignalResult {
        if kill(pid, signal) == 0 { return .sent }
        switch errno {
        case EPERM: return .notAllowed
        case ESRCH: return .alreadyGone
        case let code: return .failed(code)
        }
    }

    public func isAlive(_ pid: Int32) -> Bool {
        kill(pid, 0) == 0 || errno == EPERM
    }

    public func quitApp(pid: Int32) -> Bool {
        quitAppHandler(pid)
    }
}

/// Quit = polite (app quit / SIGTERM). Kill = SIGKILL, used while ⌥ is held.
public struct ProcessActions: Sendable {
    private let signaller: any ProcessSignaller

    public init(signaller: any ProcessSignaller) {
        self.signaller = signaller
    }

    public func canAct(on entity: Entity) -> Bool {
        entity.ownedByCurrentUser
    }

    public func canAct(on sample: ProcessSample, currentUID: UInt32) -> Bool {
        sample.process.uid == currentUID
    }

    public func quit(_ entity: Entity) -> SignalResult {
        if let main = entity.mainPID, signaller.quitApp(pid: main) { return .sent }
        return Self.combine(entity.members.map { signaller.send(SIGTERM, to: $0.process.pid) })
    }

    public func kill(_ entity: Entity) -> SignalResult {
        var pids = entity.members.map(\.process.pid)
        if let main = entity.mainPID, let index = pids.firstIndex(of: main) {
            pids.swapAt(0, index)
        }
        return Self.combine(pids.map { signaller.send(SIGKILL, to: $0) })
    }

    public func quit(_ sample: ProcessSample) -> SignalResult {
        signaller.send(SIGTERM, to: sample.process.pid)
    }

    public func kill(_ sample: ProcessSample) -> SignalResult {
        signaller.send(SIGKILL, to: sample.process.pid)
    }

    public func isAlive(_ pid: Int32) -> Bool {
        signaller.isAlive(pid)
    }

    static func combine(_ results: [SignalResult]) -> SignalResult {
        if results.contains(.notAllowed) { return .notAllowed }
        if let failure = results.first(where: { if case .failed = $0 { true } else { false } }) { return failure }
        if !results.isEmpty, results.allSatisfy({ $0 == .alreadyGone }) { return .alreadyGone }
        return .sent
    }
}
```

```swift
import Foundation

/// Recent per-entity values for the popover sparklines.
public struct UsageHistory: Sendable {
    public struct Point: Equatable, Sendable {
        public let time: TimeInterval
        public let cpuPercent: Double
        public let memoryBytes: UInt64
    }

    /// Longest window any preset uses (Chill memory, 15 min).
    public var retention: TimeInterval
    private var points: [EntityKey: [Point]] = [:]

    public init(retention: TimeInterval = 900) {
        self.retention = retention
    }

    public mutating func record(_ entities: [Entity], now: TimeInterval) {
        let cutoff = now - retention
        for entity in entities {
            points[entity.key, default: []].append(
                Point(time: now, cpuPercent: entity.cpuPercent, memoryBytes: entity.memoryBytes)
            )
        }
        points = points.compactMapValues { series in
            let kept = series.filter { $0.time >= cutoff }
            return kept.isEmpty ? nil : kept
        }
    }

    /// Values since `since`, oldest first; CPU in percent, memory in bytes.
    public func series(for key: EntityKey, resource: Resource, since: TimeInterval) -> [Double] {
        (points[key] ?? []).filter { $0.time >= since }.map { point in
            switch resource {
            case .cpu: point.cpuPercent
            case .memory: Double(point.memoryBytes)
            }
        }
    }

    public mutating func reset() {
        points = [:]
    }
}
```

```swift
import Foundation

/// Everything that happens per tick after sampling: breaches → mood → alerts, plus history.
public struct WatchPipeline: Sendable {
    public struct Step: Equatable, Sendable {
        public let mood: DogMood
        public let breaches: [Breach]
        public let newAlerts: [Breach]
    }

    public private(set) var tracker = BreachTracker()
    public var engine = MoodEngine()
    public private(set) var history = UsageHistory()

    public init() {}

    public mutating func step(
        entities: [Entity],
        limits: Limits,
        physicalMemory: UInt64,
        isMuted: (EntityKey) -> Bool,
        paused: Bool,
        now: TimeInterval
    ) -> Step {
        history.record(entities, now: now)
        // Pausing drops running timers so resuming never barks instantly.
        if paused { tracker.reset() }
        let breaches = paused
            ? []
            : tracker.update(entities: entities, limits: limits, physicalMemory: physicalMemory, now: now)
        let alerts = engine.evaluate(breaches: breaches, isMuted: isMuted, paused: paused, now: now)
        return Step(mood: engine.mood, breaches: breaches, newAlerts: alerts)
    }

    /// After sleep/wake or a clock jump: no time spent asleep counts toward a bark.
    public mutating func resetTimers() {
        tracker.reset()
        engine.reset()
    }
}
```

```swift
    private var portraitCache: [DogMood: NSImage] = [:]

        if let cached = frameCache[mood] { return cached }
        let images = PixelArt.frames(for: mood).map { Self.render($0, pixel: 1.5, template: mood != .barking) }
        frameCache[mood] = images
        return images
    }

    func frameDuration(for mood: DogMood) -> TimeInterval {
        switch mood {
        case .barking: 0.25
        case .proud: 0.3
        case .napping: 1.2
        default: 0.6
        }
    }

    func portrait(for mood: DogMood) -> NSImage {
        if let cached = portraitCache[mood] { return cached }
        let image = Self.render(PixelArt.frames(for: mood)[0], pixel: 4, template: false)
        portraitCache[mood] = image
        return image
    }

    /// Template images ignore color: only alpha matters, so `r`/`p` read as ink there.
    static func render(_ rows: [String], pixel: CGFloat, template: Bool) -> NSImage {
        let size = NSSize(width: CGFloat(PixelArt.width) * pixel, height: CGFloat(PixelArt.height) * pixel)
        let image = NSImage(size: size, flipped: true) { _ in
            for (y, row) in rows.enumerated() {
                for (x, char) in row.enumerated() {
                    let color: NSColor
                    switch char {
                    case "#": color = template ? .black : .labelColor
                    case "r": color = .systemRed
                    case "p": color = .systemPink
                    default: continue
                    }
                    color.setFill()
                    NSRect(x: CGFloat(x) * pixel, y: CGFloat(y) * pixel, width: pixel, height: pixel).fill()
                }
            }
            return true
        }
        image.isTemplate = template
        return image
    }
}
```

```swift
import AppKit
import Observation
import WoofCore
import os

enum PopoverMode: Equatable {
    case list
    case alert
}

/// Identifies a popover row: a whole entity (pid nil) or one process inside it.
struct RowID: Hashable {
    let entity: EntityKey
    let pid: Int32?
}

enum RowStatus: Equatable {
    case askingPolitely
    case stillAlive
    case notAllowed
    case gone
    case failed(Int32)
}

enum SortResource: String, CaseIterable {
    case cpu, memory
}

/// Main-actor hub: runs the sampling loop, owns the pipeline, and exposes state to the UI.
@MainActor
@Observable
final class AppCoordinator {
    static let tickInterval: TimeInterval = 2
    static let calmBatteryTickInterval: TimeInterval = 5
    static let politeQuitGrace: Duration = .seconds(5)

    let settings: SettingsStore
    private(set) var entities: [Entity] = []
    private(set) var breaches: [Breach] = []
    private(set) var mood: DogMood = .napping
    private(set) var alertingKeys: Set<EntityKey> = []
    private(set) var rowStatus: [RowID: RowStatus] = [:]
    var popoverMode: PopoverMode = .list
    var sortResource: SortResource = .cpu

    @ObservationIgnored var onMoodChange: ((DogMood) -> Void)?
    @ObservationIgnored var onAlert: (() -> Void)?
    @ObservationIgnored var onTick: (() -> Void)?

    @ObservationIgnored private var pipeline = WatchPipeline()
    @ObservationIgnored private let sampler: Sampler
    @ObservationIgnored private let actions: ProcessActions
    @ObservationIgnored private var loop: Task<Void, Never>?
    @ObservationIgnored private var observers: [NSObjectProtocol] = []
    @ObservationIgnored private let log = Logger(subsystem: "com.woofwoofcpu", category: "coordinator")
    let currentUID = getuid()

    init(settings: SettingsStore, sampler: Sampler, actions: ProcessActions) {
        self.settings = settings
        self.sampler = sampler
        self.actions = actions
    }

    var skin: any Skin { SkinRegistry.skin(id: settings.skinID) }
    var limits: Limits { settings.limits }

    // MARK: Loop

    func start() {
        observeSleepWake()
        startLoop()
    }

    private func startLoop() {
        loop?.cancel()
        loop = Task { [weak self] in
            while !Task.isCancelled {
                guard let self else { return }
                await self.tick()
                let calm = self.mood == .napping && SystemInfo.isOnBattery
                let interval = calm ? Self.calmBatteryTickInterval : Self.tickInterval
                try? await Task.sleep(for: .seconds(interval))
            }
        }
    }

    func tick() async {
        let now = SystemInfo.uptime
        let sampled = await sampler.sample(now: now)
        apply(sampled, now: now)
    }

    func apply(_ sampled: [Entity], now: TimeInterval) {
        let date = Date()
        settings.pruneExpired(now: date)
        let step = pipeline.step(
            entities: sampled,
            limits: settings.limits,
            physicalMemory: SystemInfo.physicalMemory,
            isMuted: { [settings] key in settings.isMuted(key, now: date) },
            paused: settings.isPaused(now: date),
            now: now
        )
        entities = sampled
        breaches = step.breaches
        let open = pipeline.engine.openAlertIDs
        alertingKeys = Set(step.breaches.filter { open.contains($0.id) }.map(\.key.entity))
        updateMood(step.mood)
        if !step.newAlerts.isEmpty {
            popoverMode = .alert
            onAlert?()
        } else if popoverMode == .alert, alertingKeys.isEmpty {
            popoverMode = .list
        }
        onTick?()
    }

    private func updateMood(_ newMood: DogMood) {
        guard newMood != mood else { return }
        mood = newMood
        onMoodChange?(newMood)
    }

    private func observeSleepWake() {
        let center = NSWorkspace.shared.notificationCenter
        observers.append(center.addObserver(forName: NSWorkspace.willSleepNotification, object: nil, queue: .main) { [weak self] _ in
            MainActor.assumeIsolated { self?.loop?.cancel() }
        })
        observers.append(center.addObserver(forName: NSWorkspace.didWakeNotification, object: nil, queue: .main) { [weak self] _ in
            MainActor.assumeIsolated {
                guard let self else { return }
                self.pipeline.resetTimers()
                Task {
                    await self.sampler.reset()
                    self.startLoop()
                }
            }
        })
    }

    // MARK: Popover data

    func breach(for key: EntityKey) -> Breach? {
        breaches.filter { $0.key.entity == key }.max { $0.progress < $1.progress }
    }

    /// Alerting entities first, then by severity, then by the chosen resource.
    var sortedEntities: [Entity] {
        let resource: Resource = sortResource == .cpu ? .cpu : .memory
        return entities.sorted { a, b in
            let aAlert = alertingKeys.contains(a.key), bAlert = alertingKeys.contains(b.key)
            if aAlert != bAlert { return aAlert }
            let aProgress = breach(for: a.key)?.progress ?? -1
            let bProgress = breach(for: b.key)?.progress ?? -1
            if aProgress != bProgress { return aProgress > bProgress }
            return a.value(for: resource) > b.value(for: resource)
        }
    }

    func series(for key: EntityKey, resource: Resource) -> [Double] {
        let window = settings.limits[resource].window
        return pipeline.history.series(for: key, resource: resource, since: SystemInfo.uptime - window)
    }

    func headlineEntity() -> (entity: Entity, breach: Breach)? {
        for entity in sortedEntities {
            if let breach = breach(for: entity.key), alertingKeys.contains(entity.key) || mood != .barking {
                return (entity, breach)
            }
        }
        return nil
    }

    // MARK: Actions

    func quit(_ entity: Entity, force: Bool) {
        let id = RowID(entity: entity.key, pid: nil)
        let result = force ? actions.kill(entity) : actions.quit(entity)
        handle(result, row: id, force: force, watchPID: entity.mainPID ?? entity.members.first?.process.pid)
    }

    func quit(_ sample: ProcessSample, in entity: Entity, force: Bool) {
        let id = RowID(entity: entity.key, pid: sample.process.pid)
        let result = force ? actions.kill(sample) : actions.quit(sample)
        handle(result, row: id, force: force, watchPID: sample.process.pid)
    }

    func canAct(on entity: Entity) -> Bool { actions.canAct(on: entity) }
    func canAct(on sample: ProcessSample) -> Bool { actions.canAct(on: sample, currentUID: currentUID) }

    private func handle(_ result: SignalResult, row: RowID, force: Bool, watchPID: Int32?) {
        log.info("action on \(String(describing: row.entity), privacy: .public) force=\(force) result=\(String(describing: result), privacy: .public)")
        switch result {
        case .sent where force:
            rowStatus[row] = nil
        case .sent:
            rowStatus[row] = .askingPolitely
            Task { [weak self] in
                try? await Task.sleep(for: Self.politeQuitGrace)
                guard let self, self.rowStatus[row] == .askingPolitely else { return }
                let alive = watchPID.map { self.actions.isAlive($0) } ?? false
                self.rowStatus[row] = alive ? .stillAlive : nil
            }
        case .notAllowed:
            rowStatus[row] = .notAllowed
        case .alreadyGone:
            rowStatus[row] = .gone
        case .failed(let code):
            rowStatus[row] = .failed(code)
        }
    }

    func snooze(_ entity: Entity, for duration: SnoozeDuration) {
        settings.snooze(entity.key, until: duration.until(from: Date()))
        reevaluate()
    }

    func ignore(_ entity: Entity) {
        for breach in breaches where breach.key.entity == entity.key {
            pipeline.engine.ignore(breachID: breach.id)
        }
        reevaluate()
    }

    func alwaysIgnore(_ entity: Entity) {
        settings.alwaysIgnore(entity.key)
        reevaluate()
    }

    /// Esc / click outside while barking → the dog sulks.
    func popoverDismissedByUser() {
        guard popoverMode == .alert else { return }
        pipeline.engine.alertDismissed()
        alertingKeys = []
        popoverMode = .list
        updateMood(pipeline.engine.mood)
    }

    func pause(for duration: TimeInterval?) {
        settings.pausedUntil = duration.map { Date().addingTimeInterval($0) } ?? .distantFuture
        reevaluate()
    }

    func resume() {
        settings.pausedUntil = nil
        reevaluate()
    }

    /// Re-run the pipeline on the last sample so actions show up immediately.
    private func reevaluate() {
        apply(entities, now: SystemInfo.uptime)
    }
}
```

```swift
/// Owns the NSStatusItem. Left click → `onLeftClick`; right click → menu from `menuProvider`.
/// AppKit rather than SwiftUI MenuBarExtra: the icon must animate and the popover must open on its own.
@MainActor
final class StatusItemController: NSObject {
    let statusItem = NSStatusBar.system.statusItem(withLength: NSStatusItem.variableLength)
    var onLeftClick: (() -> Void)?
    var menuProvider: (() -> NSMenu)?

    var button: NSStatusBarButton? { statusItem.button }

    override init() {
        super.init()
        guard let button = statusItem.button else { return }
        button.target = self
        button.action = #selector(clicked(_:))
        button.sendAction(on: [.leftMouseUp, .rightMouseUp])
        button.imagePosition = .imageOnly
    }

    @objc private func clicked(_ sender: NSStatusBarButton) {
        let event = NSApp.currentEvent
        if event?.type == .rightMouseUp || event?.modifierFlags.contains(.control) == true {
            guard let menu = menuProvider?() else { return }
            statusItem.menu = menu
            sender.performClick(nil)
            statusItem.menu = nil
        } else {
            onLeftClick?()
        }
    }

    /// Screen rect of the dog, used to anchor the popover. Nil if the menu bar isn't on screen.
    var anchorRect: NSRect? {
        guard let button, let window = button.window, window.isVisible else { return nil }
        return window.convertToScreen(button.convert(button.bounds, to: nil))
    }
}
```

```swift
import AppKit
import WoofCore

/// Cycles the current skin's frames for the current mood on the status item button.
@MainActor
final class DogAnimator {
    private weak var button: NSStatusBarButton?
    private var skin: any Skin
    private var mood: DogMood = .napping
    private var frameIndex = 0
    private var timer: Timer?

    init(button: NSStatusBarButton?, skin: any Skin) {
        self.button = button
        self.skin = skin
        restart()
    }

    func update(mood: DogMood, skin: any Skin) {
        guard mood != self.mood || skin.id != self.skin.id else { return }
        self.mood = mood
        self.skin = skin
        restart()
    }

    private func restart() {
        timer?.invalidate()
        timer = nil
        frameIndex = 0
        show()
        guard skin.frames(for: mood).count > 1 else { return }
        timer = Timer.scheduledTimer(withTimeInterval: skin.frameDuration(for: mood), repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.advance() }
        }
    }

    private func advance() {
        frameIndex += 1
        show()
    }

    private func show() {
        let frames = skin.frames(for: mood)
        guard !frames.isEmpty else { return }
        button?.image = frames[frameIndex % frames.count]
        button?.setAccessibilityLabel("woofWoofCPU — \(mood.rawValue)")
    }
}
```

```swift
import Foundation
import WoofCore

enum Formatting {
    static func value(_ value: Double, for resource: Resource) -> String {
        switch resource {
        case .cpu: "\(Int(value.rounded()))%"
        case .memory: ByteCountFormatter.string(fromByteCount: Int64(value), countStyle: .memory)
        }
    }

    static func duration(_ seconds: TimeInterval) -> String {
        let formatter = DateComponentsFormatter()
        formatter.allowedUnits = seconds >= 3600 ? [.hour, .minute] : [.minute, .second]
        formatter.unitsStyle = .abbreviated
        return formatter.string(from: max(0, seconds)) ?? ""
    }

    static func limit(_ limits: Limits, _ resource: Resource) -> String {
        let threshold = limits.thresholdValue(for: resource, physicalMemory: SystemInfo.physicalMemory)
        return "limit \(value(threshold, for: resource)) for \(duration(limits[resource].window))"
    }
}
```

```swift
/// The dog's funny lines. `{app}`, `{value}`, `{duration}` are substituted.
enum Lines {
    static func line(mood: DogMood, resource: Resource?, app: String?, value: String, duration: String, seed: Int) -> String {
        let bank: [String]
        switch (mood, resource) {
        case (.barking, .cpu?), (.growling, .cpu?):
            bank = [
                "{app} is chewing all the CPU!",
                "WOOF! {app} won't stop zooming around!",
                "{app} has the zoomies. {value} for {duration}.",
            ]
        case (.barking, .memory?), (.growling, .memory?):
            bank = [
                "{app} is hoarding all the kibble ({value})!",
                "{app} buried {value} of bones and won't share.",
            ]
        case (.sniffing, _):
            bank = ["Sniff sniff… {app} smells busy."]
        case (.sulking, _):
            bank = ["Fine. I'll just keep an eye on {app}. 🙄"]
        case (.proud, _):
            bank = ["Good human. 🦴", "Bad app chased off!"]
        default:
            bank = ["All quiet. Zzz…"]
        }
        let template = bank[abs(seed) % bank.count]
        return template
            .replacingOccurrences(of: "{app}", with: app ?? "Something")
            .replacingOccurrences(of: "{value}", with: value)
            .replacingOccurrences(of: "{duration}", with: duration)
    }
}
```

```swift
import AppKit
import Observation

/// Polls the ⌥ key while the popover is open. Polling `NSEvent.modifierFlags` needs no
/// Accessibility permission, unlike a global flagsChanged monitor for a non-active app.
@MainActor
@Observable
final class OptionKeyMonitor {
    private(set) var isOptionDown = false
    @ObservationIgnored private var timer: Timer?

    func start() {
        guard timer == nil else { return }
        timer = Timer.scheduledTimer(withTimeInterval: 0.1, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated {
                let down = NSEvent.modifierFlags.contains(.option)
                if self?.isOptionDown != down { self?.isOptionDown = down }
            }
        }
    }

    func stop() {
        timer?.invalidate()
        timer = nil
        isOptionDown = false
    }
}
```

```swift
import SwiftUI

/// Recent values with a dashed limit line, so you can see why the dog barked.
struct Sparkline: View {
    let values: [Double]
    let limit: Double
    var color: Color = .accentColor

    var body: some View {
        Canvas { context, size in
            let top = max(values.max() ?? 0, limit) * 1.15
            guard top > 0 else { return }
            func y(_ value: Double) -> CGFloat { size.height - CGFloat(value / top) * size.height }

            var limitLine = Path()
            limitLine.move(to: CGPoint(x: 0, y: y(limit)))
            limitLine.addLine(to: CGPoint(x: size.width, y: y(limit)))
            context.stroke(limitLine, with: .color(.secondary), style: StrokeStyle(lineWidth: 1, dash: [3, 3]))

            guard values.count > 1 else { return }
            let step = size.width / CGFloat(values.count - 1)
            var line = Path()
            for (index, value) in values.enumerated() {
                let point = CGPoint(x: CGFloat(index) * step, y: y(value))
                index == 0 ? line.move(to: point) : line.addLine(to: point)
            }
            context.stroke(line, with: .color(color), lineWidth: 1.5)
        }
        .accessibilityHidden(true)
    }
}
```

```swift
        let top = coordinator.headlineEntity()
        let resource = top?.breach.key.resource
        let value = top.map { Formatting.value($0.breach.lastValue, for: $0.breach.key.resource) } ?? ""
        let duration = top.map { Formatting.duration(SystemInfo.uptime - $0.breach.since) } ?? ""
        return Lines.line(
            mood: coordinator.mood,
            resource: resource,
            app: top?.entity.displayName,
            value: value,
            duration: duration,
            seed: top?.breach.id ?? 0
        )
    }

    private var subline: String? {
        if coordinator.settings.isPaused(now: Date()), let until = coordinator.settings.pausedUntil {
            return until == .distantFuture ? "Off duty until you resume" : "Off duty until \(until.formatted(date: .omitted, time: .shortened))"
        }
        guard let top = coordinator.headlineEntity() else { return nil }
        return Formatting.limit(coordinator.limits, top.breach.key.resource)
    }

    private var orderedEntities: [Entity] {
        let sorted = coordinator.sortedEntities
        guard let frozenOrder else { return sorted }
        let rank = Dictionary(uniqueKeysWithValues: frozenOrder.enumerated().map { ($1, $0) })
        return sorted.sorted { (rank[$0.key] ?? Int.max) < (rank[$1.key] ?? Int.max) }

                    .font(.system(size: 11))
                    .padding(.leading, 6)
            }
        }

        }

        }
        .font(.system(size: 11))
    }
```

```swift
import AppKit
import SwiftUI

/// Non-activating panel so the popover never steals keyboard focus, and can float over full-screen apps.
final class PopoverPanel: NSPanel {
    var onCancel: (() -> Void)?

    init() {
        super.init(
            contentRect: NSRect(x: 0, y: 0, width: 380, height: 300),
            styleMask: [.nonactivatingPanel, .borderless, .fullSizeContentView],
            backing: .buffered,
            defer: true
        )
        isFloatingPanel = true
        level = .statusBar
        collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]
        hidesOnDeactivate = false
        isMovable = false
        isOpaque = false
        backgroundColor = .clear
        hasShadow = true
    }

    override var canBecomeKey: Bool { true }

    override func cancelOperation(_ sender: Any?) {
        onCancel?()
    }
}

@MainActor
final class PopoverController {
    private let panel = PopoverPanel()
    private let status: StatusItemController
    private let optionKey: OptionKeyMonitor
    private var clickMonitor: Any?

    /// Called when the user dismisses the popover (Esc or click outside), not when we close it.
    var onUserDismiss: (() -> Void)?

    var isShown: Bool { panel.isVisible }

    init<Content: View>(status: StatusItemController, optionKey: OptionKeyMonitor, content: Content) {
        self.status = status
        self.optionKey = optionKey
        let host = NSHostingController(
            rootView: content.background(.regularMaterial, in: RoundedRectangle(cornerRadius: 12))
        )
        host.sizingOptions = [.preferredContentSize]
        panel.contentViewController = host
        panel.onCancel = { [weak self] in self?.dismissByUser() }
    }

    func toggle() {
        isShown ? dismissByUser() : show()
    }

    func show() {
        panel.contentViewController?.view.layoutSubtreeIfNeeded()
        position()
        panel.orderFrontRegardless()
        panel.makeKey()
        optionKey.start()
        if clickMonitor == nil {
            clickMonitor = NSEvent.addGlobalMonitorForEvents(matching: [.leftMouseDown, .rightMouseDown]) { [weak self] _ in
                MainActor.assumeIsolated { self?.dismissByUser() }
            }
        }
    }

    func close() {
        if let clickMonitor { NSEvent.removeMonitor(clickMonitor) }
        clickMonitor = nil
        optionKey.stop()
        panel.orderOut(nil)
    }

    private func dismissByUser() {
        guard isShown else { return }
        close()
        onUserDismiss?()
    }

    /// Under the dog when the menu bar is visible; top-right of the active screen in full-screen.
    private func position() {
        let size = panel.contentViewController?.view.fittingSize ?? panel.frame.size
        let screen = NSScreen.main ?? NSScreen.screens[0]
        var origin: NSPoint
        if let anchor = status.anchorRect {
            origin = NSPoint(x: anchor.midX - size.width + 40, y: anchor.minY - size.height - 6)
        } else {
            origin = NSPoint(x: screen.frame.maxX - size.width - 12, y: screen.frame.maxY - size.height - 8)
        }
        let bounds = screen.visibleFrame
        origin.x = min(max(origin.x, bounds.minX + 8), bounds.maxX - size.width - 8)
        panel.setFrame(NSRect(origin: origin, size: size), display: true)
    }
}
```

```swift
    func applicationDidFinishLaunching(_ notification: Notification) {

        )
        // ProcessActions is only driven from the popover, i.e. on the main thread.

            MainActor.assumeIsolated { NSRunningApplication(processIdentifier: pid)?.terminate() ?? false }
        })
        coordinator = AppCoordinator(settings: settings, sampler: sampler, actions: ProcessActions(signaller: signaller))
        settingsWindow = SettingsWindowController(settings: settings)

        status = StatusItemController()
        animator = DogAnimator(button: status.button, skin: coordinator.skin)
        popover = PopoverController(
            status: status,
            optionKey: optionKey,
            content: PopoverView(coordinator: coordinator, optionKey: optionKey) { [weak self] in
                self?.popover.close()
                self?.settingsWindow.show()
            }
        )

        status.onLeftClick = { [weak self] in
            guard let self else { return }
            if !self.popover.isShown { self.coordinator.popoverMode = .list }
            self.popover.toggle()
        }
        status.menuProvider = { [weak self] in self?.makeMenu() ?? NSMenu() }
        popover.onUserDismiss = { [weak self] in self?.coordinator.popoverDismissedByUser() }
        coordinator.onMoodChange = { [weak self] _ in self?.refreshDog() }
        coordinator.onTick = { [weak self] in self?.refreshDog() }
        coordinator.onAlert = { [weak self] in
            guard let self else { return }
            self.popover.show()
            if !self.coordinator.settings.soundMuted { self.bark.play(self.coordinator.skin.barkSoundName) }
        }

        coordinator.start()
    }

    private func refreshDog() {
        animator.update(mood: coordinator.mood, skin: coordinator.skin)
    }

    private func makeMenu() -> NSMenu {
        let menu = NSMenu()
        let paused = coordinator.settings.isPaused(now: Date())
        if paused {
            menu.addItem(ClosureMenuItem("Resume watching") { [weak self] in self?.coordinator.resume() })
        } else {
            menu.addItem(ClosureMenuItem("Pause for 30 minutes") { [weak self] in self?.coordinator.pause(for: 30 * 60) })
            menu.addItem(ClosureMenuItem("Pause for 1 hour") { [weak self] in self?.coordinator.pause(for: 60 * 60) })
            menu.addItem(ClosureMenuItem("Pause until I resume") { [weak self] in self?.coordinator.pause(for: nil) })
        }
        menu.addItem(.separator())
        let mute = ClosureMenuItem("Mute bark") { [weak self] in self?.coordinator.settings.soundMuted.toggle() }
        mute.state = coordinator.settings.soundMuted ? .on : .off
        menu.addItem(mute)
        menu.addItem(ClosureMenuItem("Settings…") { [weak self] in self?.settingsWindow.show() })
        menu.addItem(.separator())
        menu.addItem(ClosureMenuItem("Quit woofWoofCPU") { NSApp.terminate(nil) })
        return menu
    }
}

/// NSMenuItem that runs a closure, so menus don't need @objc selectors per item.
final class ClosureMenuItem: NSMenuItem {
    private let handler: () -> Void

    init(_ title: String, handler: @escaping () -> Void) {
        self.handler = handler
        super.init(title: title, action: #selector(run), keyEquivalent: "")
        target = self
    }

    required init(coder: NSCoder) { fatalError("not used") }

    @objc private func run() { handler() }
}
```

`scripts/hog.sh` (then run `chmod +x scripts/hog.sh`):

```bash
#!/bin/bash
# Deliberately hogs a resource so the dog has something to bark at.
#   scripts/hog.sh cpu [seconds]        burn one core (default 300 s)
#   scripts/hog.sh mem [GB] [seconds]   hold GB of touched memory (default 4 GB, 300 s)
set -euo pipefail

case "${1:-}" in
  cpu)
    secs="${2:-300}"
    yes > /dev/null &
    pid=$!
    trap 'kill $pid 2>/dev/null || true' EXIT
    echo "Burning one core as 'yes' (pid $pid) for ${secs}s…"
    sleep "$secs"
    ;;
  mem)
    gb="${2:-4}"
    secs="${3:-300}"
    echo "Holding ${gb} GB in python3 for ${secs}s…"
    python3 -c "
import time
b = bytearray(int($gb * 1024**3))
for i in range(0, len(b), 4096): b[i] = 1
time.sleep($secs)
"
    ;;
  *)
    echo "usage: $0 cpu [seconds] | mem [GB] [seconds]" >&2
    exit 1
    ;;
esac
```
